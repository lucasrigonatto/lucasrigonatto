# Hi, I'm Lucas

I'm a software engineer interested in enterprise applications, systems integration, and web development. I like turning a concrete workflow into software that is clear to use and straightforward to maintain.

## Selected work

- **[Entrelinhas](https://github.com/lucasrigonatto/entrelinhas)** — a bilingual blog with authentication, private drafts, ownership checks, and automated tests.
- **[Cerâmica Leide](https://github.com/lucasrigonatto/ceramica-leide)** — a responsive business website with product information, service regions, and direct contact paths. [Website](https://www.ceramicaleide.com.br)
- **[Photography Portfolio](https://github.com/lucasrigonatto/portfolio-fotografa)** — a Next.js and Supabase portfolio with booking requests and a separate admin area.
- **[Mirante Vet](https://github.com/lucasrigonatto/mirante-vet)** — an OutSystems 11 clinic-management MVP with separate Core and FrontOffice modules.
- **[Ratebook](https://github.com/lucasrigonatto/exchange-rate-site)** — a daily exchange-rate dashboard with base-currency selection, filtering, and tested error handling.
- **[Currency](https://github.com/lucasrigonatto/Currency)** — a focused converter using daily reference rates.

Each project explains the problem, the implementation, how to run it, and what validation is available. Where a service or runtime needs separate configuration, the documentation makes that explicit.
